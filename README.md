# Epiphany Journal

English | [简体中文](README_CN.md)

**Epiphany Journal** is a lightweight compatibility mod that bridges [Epiphany](https://www.curseforge.com/minecraft/mc-mods/epiphany-mod) and [Loot Journal](https://www.curseforge.com/minecraft/mc-mods/loot-journal-neoforge). With this mod, all notifications for Epiphany's modules/epiphanies unlocked and Insight Point gains will be displayed via Loot Journal's loot popup notifications.

> If you prefer not to see the notification messages powered by Epiphany, please disable the relevant options in the Epiphany mod's configuration.
