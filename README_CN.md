# Epiphany Journal

[English](README.md) | 简体中文

**Epiphany Journal** 是一个轻量级联动模组，旨在将 [Epiphany](https://www.mcmod.cn/class/28680.html) 与 [Loot Journal](https://www.mcmod.cn/class/8945.html) 的功能衔接起来。安装后，Epiphany 中的“模块/顿悟”解锁提示以及心得点获得提示，都会通过 Loot Journal 的拾取提示弹窗进行展示。

> 如果你不希望保留原版的信息提示，请在 Epiphany 的配置文件中关闭对应选项。
